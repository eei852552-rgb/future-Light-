# Changelog

All notable changes to Future Light should be recorded here.

## [1.0.0] — 2026-10-11

### Added

- Mobile-first Future Light editor shell with original branding.
- Local file/folder explorer with create, import, rename, delete and backup/restore.
- HTML, CSS, JavaScript, JSON and text editing with tabs and syntax highlighting.
- Search/replace, replace all, undo/redo, copy/cut/select-all and indentation.
- Local autosave, recovery snapshot and unsaved-change warnings.
- HTML/CSS/JavaScript live preview.
- Dark/light themes and editor settings.
- PWA manifest and reusable module structure.

### Known limitations

- This release is a browser/PWA foundation; no signed APK or AAB was generated in the current sandbox.
- Native terminal, Git, code completion, language-server diagnostics, plugins and formatter integrations are planned extensions.
